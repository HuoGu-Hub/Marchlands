# Marchlands 网格导航与地形编辑

**状态** 数据层、导航核心与编辑器地形工具已接入；兵团网格移动尚未接入，运行时仍走据点图。

## 数据

- `MapDocument` schema 3：`navigation`、`grid`、`vision`、道路样条、城镇占地与占领半径、装饰阻挡字段。
- `MapDef` schema 2：`navigation`、`grid`、`mapHash`、城镇 `footprintCm`/`captureRadiusCm`。
- schema 1/2 文档载入时升级为 schema 3，导航模式为 `graph`。
- 网格数据：1 米格、整数厘米高度、地表枚举、阻挡位图、可走覆盖位图；运行时序列化为 Base64。
- `mapHash` 由 `mapHashOf` 对排序后的地图 JSON 计算，排除自身字段。

## 导航核心

`packages/nav` 提供不依赖引擎的整数网格：

- 8 方向 A*，禁止贴角，固定 (f, 格子索引) 排序。
- 坡度、台阶、深水、阻挡与单位半径膨胀。
- 道路/泥地/浅水代价，上坡与下坡倍率。
- 路径平滑、世界坐标双线性高度采样、Base64 打包。

默认规则：1 米格、最大坡度 35°、最大台阶 30 cm、对角代价 1414/1000、步兵半径 40 cm、骑兵半径 80 cm。

```ts
const path = planPath(grid, { xCm: 50, zCm: 50 }, { xCm: 2450, zCm: 1850 }, { radiusCm: 40 });
```

## 编辑器

- 新建网格地图或把现有据点图转换为网格。
- 地形刷：抬高、降低、平滑、坡道、悬崖、水面、地表、阻挡、可走覆盖。
- 导航预览：显示阻挡、水面、道路、陡坎与可走覆盖。
- 路径测试：点起点终点，用 40 cm 半径跑 A*，显示路径、格数与代价。
- 编译校验：网格尺寸、高度/地表范围、位图长度、城镇出生格与互相可达性。
