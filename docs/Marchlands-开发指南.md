## 0. 开始前先读这三条

1. **只做 M1。** 当前做三张官方图、玩家地图编辑器、单机一局、完整页面。Agent、服务器、法术、塔、城堡不做；粮草、临时驻兵点、行军改道按 [ADR 0002](adr/0002-granary-outpost.md) 与 [ADR 0003](adr/0003-squad-reroute-supply.md) 执行，不另加机制。
2. **不复制原作资产与关卡。** .work/original 只读，用于理解规则和节奏；不把原作 PNG、OGG、文本、坐标或节点直接放进项目。
3. **模拟核心保持纯净。** packages/sim 不得 import Cocos、DOM、Node API；不得使用 Math.random、Date.now；所有随机来自种子。

**当前下一步** 建仓库骨架；先落 forest01.json、rules/1.json 和页面流程图，不写 3D 美术。

如果任务超出“做与不做”清单，先停下，向用户确认，不要自行扩张。

### 0.1 工作方式

- 每次只做一个里程碑子项，完成后再开下一个。
- 先改本文件的契约，再改代码；不要默默改规则。
- 每完成一项，更新第 15 节的勾选状态。
- 不把 .work 加入版本库，不把原作资源放进构建。
- 如果初始化 git，按模块提交，提交信息用中文；不要提交 .work、build、library、temp。
- 遇到阻塞，记录在 docs/blockers.md，写清楚复现、影响和需要的决定。

## 1. M1 完成定义

M1 完成 = 以下全部成立：

- 从主菜单开始 forest01，1 人类 + 1 AI，7 座城，能完整打完一局。
- 能赢、能输、能重开、能回主菜单、能退出。
- 所有页面可走通：启动、主菜单、简报、对局、暂停、结算、设置、退出确认。
- 1280×720 与 1920×1080 下页面不重叠、不缺字、没有无响应按钮。
- 目标机器 1080p 60 帧；加载 forest01 不超过 5 秒。
- Node 与 PC 客户端对同一指令流得到相同状态哈希。
- 3 节点高低差测试场景能跑：单位上下坡、四向可见、城市不悬空。
- 10 名外部玩家能自行完成一局；0 个 P0/P1 缺陷。

不满足以上任何一条，M1 不算完成。

## 2. 本轮范围

### 2.1 做

- 3 张官方图：forest01、crossroads01、frontier01；玩家可以用地图编辑器生成自己的图。
- 玩家地图编辑器：图结构草稿、拖放城镇/粮仓/驻兵点、连路、属性编辑、撤销、实时校验、试玩、保存/载入与自定义地图持久化。
- 1 人类 + 1 AI；2 个玩家。
- 城镇与中立城；派兵、行军、战斗、占领、升级。
- 粮仓：不产兵、可屯兵、为全队提供速度与战斗力增幅；不产金币、不可升级。
- 临时驻兵点：路边叶子据点，可屯兵、会掉兵、可设避战/迎战；不计入胜负。
- 行军改道：点击路上兵团查看路线，在下一个岔路口前改道或改目的地。
- 兵团粮草：出发携带，安全行军一段时间后开始掉兵。
- 人口增长、金币收入与 HUD 显示；不做金币消费。
- 胜负：占满当地图全部城镇或消灭 AI；15 分钟硬上限，按城镇数与城镇人口判定。
- 3D 地形、四向镜头、单位、选中与派兵交互。
- 完整页面流程与设置。
- 设置持久化、重开、结算统计；不做对局中途存档。
- 3 节点高低差测试场景，只验证管线，不作为正式关卡。

### 2.2 不做

- 不做第四张官方图、不做 5 图、不做 15 图；官方图之外的地图由玩家编辑器生成。
- 不做网格瓦片寻路与建筑独立玩法；据点和道路仍然决定行军与胜负。地形高度参与道路贴地、兵团贴地与坡度代价，但不提供自由瓦片导航。
- 不做塔、城堡、铁匠铺、马厩、法术、市场、高地战斗加成；粮仓与临时驻兵点按 ADR 0002 例外。
- 不做 Agent、MCP、HTTP、在线榜单、账号、服务器。
- 不做人类 PvP、在线地图工坊、移动端、全程配音、第二生态；玩家地图与回放先存本地。
- 不做自由 360° 镜头，不做实时方向光阴影，不做破坏地形。

### 2.5 地图编辑器

- 数据层在 `packages/map-authoring`：`MapDocument` 是编辑器唯一真相，`compileDocument` 计算边长、生成 `MapDef` 并运行内容校验。
- 据点类型统一为：兵营、马厩、盾兵营、弓兵营、粮仓、驻兵点；城镇类型已移除，旧文档里的 town 读取时迁移为兵营。只有四个产兵据点能派兵，粮仓与驻兵点不产兵。
- 编辑器编辑图结构与视觉层：据点、道路、归属、等级、驻军、驻兵点监视边、地图尺寸、通行规则、地貌风格、道路风格、地基、地形块、树木/岩石/场景装饰、据点建筑外观。视觉层不进入模拟；地形高度只通过编译出的边坡度影响寻路代价。
- 地基是地图的实体元素：`visual.foundations` 保存一组矩形平台，每块有中心、尺寸、顶面高度、厚度与可选外壳模型。编辑器可新增、删除、复制、拖动、拖角或拖边改尺寸、改高度与厚度。向边缘外侧新增会扩大地图范围，抬高或独立放置会得到浮空岛。
- 同高度且并集仍是矩形的相邻地基会自动合并成一块，避免接缝处出现双层浮岛。不同外壳、外形或不同高度的地基保持独立。地图可编辑范围取地基并集，据点、道路控制点与装饰都按这个范围校验。
- 补景不再生成不可选的 InstancedMesh：地基检查器可以设置“每次数量”，点一次“补景”就在这块地基的空闲位置放入一批真实装饰 props，避开道路、据点、边界和已有装饰；再次点击继续补，不会固定生成在同一位置。每次数量默认 6，范围 1–30。
- 移动地基时，落在这块地基范围内的据点、装饰和道路控制点会一起平移，不会只留下地基。调整地基高度时，地表上的物品仍按新高度重新贴地。
- 设置按对象拆分：地图设置只保留名称、对局时间、起始金币；道路风格/宽度在选中道路后显示；据点通行规则在选中据点后显示；地基地貌/风格/种子/起伏/贴图/外形/补景在选中地基后显示。
- 渲染层按地基逐块生成顶面与浮岛外壳；`heightAt` 返回覆盖该点且顶面最高的地基高度，所以据点、装饰、道路与植被会自然落在对应平台上。镜头取景按所有浮岛外沿的并集计算。
- 网格地图只支持一块与网格同心的地基，尺寸随地图宽高变化；网格地图里的地基不能移动、缩放或抬高。
- 建筑优先读取 GLB：兵营/马厩/盾兵营/弓兵营/塔楼/粮仓来自转换后的建筑资产；单位外观由玩家在开局前按兵种选择，地图不再保存整方单位覆盖；缺失时回退程序化模型。
- 自动补景已停用，场景里的树木/岩石/草丛只来自地图的显式 props；编辑器和试玩看到的是同一批对象。
- 资产通过稳定 ID 引用：内置资产使用 `builtin:`，玩家资产包使用 `命名空间:路径`。详细格式见 [资产包格式](Marchlands-资产包.md)。
- 默认“地图编辑器”是新版：PCUI 壳、自由环绕相机、XYZ 手柄与大纲/检查器；支持地基拖拽创建、面手柄扩建、抬高、复制、删除，据点/装饰的选择与变换，道路绘制与控制点拖动，网格地形转换与笔刷，地基地貌/材质切换、自定义贴图、六种地基外形与尺寸预设、单块地基贴图，OBJ/MTL/贴图转 GLB，资产包导入导出与移除，对局时间与起始金币、导航预览和通行规则。单位外观在开局前的兵团皮肤面板里选择。需要旧版工具时打开 `?editor=classic` 回退。
- 通行规则：建筑有放行/拦截两种状态。己方建筑永远放行；非己方建筑按当前状态判定，放行可直接通过，拦截需要战斗攻占。中立建筑的状态在地图创建时固定、局内不可改；被占领后由占领方在局内切换。地图文档的 `transit` 是中立建筑的缺省值。
- 网格兵种档案：步兵/弓兵 500cm 高差、盾兵 500cm 且 2×1 占地、骑兵 2000cm、精兵 10000cm；地表和宽通道按兵种过滤，盾兵需要 2×2 转弯空间。
- 操作：选择/移动工具下左键拖动平移；旋转/缩放工具下左键拖动 XYZ 圆环或轴，平移用中键；右键环绕，滚轮缩放。放置、道路、地形工具下左键用于绘制，平移用中键。拖拽素材或点击素材后点地面放置；选择工具拖动据点、装饰或地基；道路工具连两点；地基模式点边缘外侧扩展地图，点空白处新增独立平台；R 旋转、T 缩放，[ ]/Shift 组合调整，Delete 删除选中对象，Ctrl+D 复制地基，PageUp/PageDown 升降地基，Ctrl+Z/Ctrl+Y 撤销重做。
- 道路模型和模拟寻路共用同一条折线：不再给直路加随机弯曲，也不再对控制点做 CatmullRom 平滑；选中道路的黄色标记同样按折线绘制，避免“线在路外、兵走线外”的错位。
- 左键拾取按“据点 → 道路 → 装饰 → 地基”排序，地基的大包围盒不再抢走装饰和道路的点击；道路用屏幕空间距离拾取，压在道路附近的树也不会挡住道路选择。选中道路后双击道路可插入控制点，拖动控制点改变形状，Alt+点击控制点删除。
- 道路上方禁止放置装饰：新建和拖动装饰时都会检查道路净距；已有地图里的压路装饰不会被自动删除，需要手动移开。
- 资产包：编辑器导入 `.mlpack`，资产写入 IndexedDB；地图只保存资产 ID，缺失时场景跳过并在状态栏提示。
- 校验：至少两座城镇、特殊据点只能有一条路、驻兵点必须有监视边且支路接触监视边端点、图必须连通、至少两座城镇；错误阻止试玩，警告不阻止。
- 保存：`.mlmap.json` 的 MapDocument；可保存到文件、载入文件、自动保存草稿。自定义地图进入简报地图下拉，并写入 localStorage。
- 试玩：编辑器把编译后的 MapDef 交给 GameSession；暂停后可返回编辑器，草稿和镜头保留。
- 验收：新建 4 据点模板，放置第 5 个据点后出现错误，撤销后恢复有效；试玩后返回，地图仍为 4 据点。

## 4. 技术栈与仓库

- 渲染：Three.js；PC 外壳：Electron；TypeScript。
- 选择原因见 docs/adr/0001-renderer.md；模拟核心与渲染完全解耦。
- 包管理：pnpm + Turborepo。
- 测试：Vitest、fast-check、Playwright。
- 首轮不引入后端、数据库、Redis、Docker。

**目标仓库结构**

~~~text
marchlands/
  apps/
    client/                 Three.js + Vite 客户端
  packages/
    sim/                    确定性模拟核心
    content/                地图、规则、文本
  tools/
    map-export/             干净房间数据导出与校验
  docs/
    Marchlands-开发指南.md
  plans/
    Marchlands-开发方案.html
  tests/
    e2e/                    Playwright 页面流程
~~~

**模块边界**

- apps/client 可以 import packages/sim 与 packages/content。
- packages/sim 只能 import packages/sim 内部文件与纯 TS 工具。
- packages/sim 不得 import Cocos、DOM、Node、fs、path、process。
- packages/content 只放数据与数据校验，不放游戏逻辑。
- tools/map-export 可以读 .work/original 做参考，但输出必须是重画后的数据，不得包含原作资源。

**建议文件**

~~~text
packages/sim/src/
  types.ts        状态、指令、事件类型
  game.ts         createGame / step / finish
~~~

## 5. 核心规则

### 5.1 时间、坐标、单位

- 模拟 20 Hz，1 tick = 50 ms。
- 首图坐标单位：分米。地图 600 × 600 dm，即 60 × 60 m。
- 渲染比例：1 dm = 0.1 m。渲染层把模拟坐标除以 10。
- 移动速度：60 dm/s = 3 dm/tick。
- 所有位置、人口、金币在模拟里用整数；人口增长与金币用“千分位余数”累积。
- 1 人口 = 1 个整数单位；内部增长用 milli-pop，1000 milli = 1 pop。
- 1 金币 = 1 个整数单位；内部收入用 milli-gold，1000 milli = 1 gold。

### 5.2 人口、金币、升级

**人口上限与升级**

| 等级 | 人口上限 | 升级消耗 | 防御系数 |
|---|---|---|---|
| 1 | 30 | 15 | 1.00 |
| 2 | 45 | 22 | 1.10 |
| 3 | 65 | 32 | 1.20 |

- 升级消耗 = 当前等级人口上限的 50%，向下取整。
- 升级条件：等级 < 3，当前人口 >= 升级消耗。
- 升级后：扣除人口、等级 +1、人口上限取新等级表、防御系数取新表。
- 首图最高 3 级。

**人口增长**

- 每秒增长：1.0 + 0.25 × (等级 - 1) pop/s。
- 每 tick 增长：50 / 62 / 75 milli-pop，对应等级 1/2/3。
- 到达人口上限停止增长。
- 被攻击后人口下降，增长继续。
- 粮仓与驻兵点不增长，只能靠派兵增援。

**金币**

- 每座己方城镇按自身等级产生收入，累加到该玩家金币；粮仓与驻兵点不产金币。
- 每 tick 收入：100 / 125 / 150 milli-gold，对应等级 1/2/3。
- 首轮只累计与显示，不消费。

### 5.3 派兵、寻路、战斗

**派兵**

- 指令只允许从己方据点出发。
- 游戏内所有地图都按网格通行：网格地图使用烘焙网格；据点图在开局按地形采样生成 1 米网格，道路只保留视觉与 AI 用途。
- 目标可以是任意可抵达网格，也可以直接选建筑。
- 派出数量 = floor(当前人口 × 50%)，最少 1。
- 当前人口 < 2 时拒绝派兵。
- 出发时立即扣除人口；到达前据点可继续增长（仅城镇）。
- 同一据点可以同时派出多支队伍。
- 每个格是否可走，由单位通行规则判定：地表类型、坡度/高差、单位半径，以及非己方建筑的占地阻挡；不依赖道路连通性。
- 以网格为终点的队伍抵达后原地驻留，可再次改道；驻留期间不结算断粮。

**寻路**

- 图是无向图；边权为两点距离。
- 用 Dijkstra 找最短路径；首图 11 个据点，直接缓存 path。
- 基础 ETA ticks = ceil(distance / 3)；粮仓速度增幅按 5.7 缩短 ETA。
- 队伍沿路径匀速移动；到达目标据点后结算。
- 同 tick 到达的多支队伍按 squadId 升序结算。
- 队伍记录 `pathIndex`、当前边开始/结束 tick；抵达中间节点只推进路径，不结算战斗。

**改道**

- 新增指令 `retarget { squad, to, via? }`。
- 指令可在任意时刻发，但在**下一个节点**生效；当前边不中途掉头。
- `via` 是下一个节点之后要走的第一跳；省略时从下一个节点走最短路径。
- 改道不重置粮草，不重复结算已发生的迎战拦截。
- UI 用 `routeOptions(graph, squad)` 获取当前路线与所有可抵达目的地的简单分支；当前路线亮色，其余暗色。点击暗色线路发送 `via`，点击据点发送新的 `to`。

**战斗**

~~~text
A = 进攻方兵力
D = floor(守方人口 × 守方防御系数)

if A > D:
    占领
    新城主 = 进攻方
    新城人口 = A - D，且不超过人口上限
else:
    守方保留
    守方人口 = min(原人口, max(0, D - A))
~~~

防御系数大于 1 时，D 可能大于原人口；守方人口不能因被攻击而增加。

- 首轮没有塔、没有铁匠铺、没有高地修正。
- 粮仓与驻兵点使用 5.7 的据点防御值；粮仓增幅会同时提高攻防。
- 守方是中立城时，防御系数按等级表。
- 若目标在到达前已被同玩家占领，按增援处理：人口相加，封顶人口上限，溢出丢弃。
- 若目标在到达前被其他玩家占领，按敌方城结算。
- 战斗结算发事件，UI 据此播特效与更新数字。

### 5.4 胜负

- 任一玩家拥有全部 7 座城镇，立即胜利。
- 任一玩家城镇数为 0，立即失败；粮仓与临时驻兵点不计入城镇数，也不能阻止淘汰。
- 到达 18000 tick，即 15 分钟：
  - 城镇数多者胜。
  - 城镇数相同，城镇总人口多者胜。
  - 再相同，金币多者胜。
  - 仍相同，平局。
- 结算后停止模拟，只允许重开或回主菜单。

### 5.5 AI

一档 AI，不读玩家操作，不用额外资源。每 40 tick，即 2 秒，决策一次：

1. 若某己方城人口 >= 60% 上限，且存在守方防御 < 出兵数的目标，向最近的可攻下目标派兵。
2. 若没有可攻下目标，且人口 >= 80% 上限、等级 < 3，升级。
3. 若人口已到 80% 且仍无必胜目标，向防御不超过出兵数 2 倍的目标派兵，避免人口顶满。
4. 若 600 tick 没有动作，最强城向最近目标派兵，保证对局推进。
5. 未拥有粮仓时优先考虑可攻下的粮仓；已拥有粮仓后不再为增益重复投资。
6. 把己方有驻军的临时驻兵点切到迎战；不主动进攻敌方驻兵点。
7. 不使用改道；按派兵时算好的最短路径行军。
8. 不主动放弃城市；不修改资源；不预测玩家指令。

AI 必须能完成：至少一次占领、一次升级、一次进攻；15 分钟内结束一局。

### 5.6 事件

每 tick 生成事件数组，UI 消费后清空。首轮事件：

| 事件 | 字段 | 用途 |
|---|---|---|
| squadSpawned | squadId, from, to, count, arrivalTick | 画队伍、播放出发 |
| squadArrived | squadId, cityId | 到达 |
| combatResolved | cityId, attacker, defender, attackerLoss, defenderLoss, captured | 数字与特效 |
| cityCaptured | cityId, fromOwner, toOwner, pop | 旗色、音效 |
| upgradeCompleted | cityId, level | 升级特效 |
| squadIntercepted | squadId, cityId, squadOwner, outpostOwner, squadLoss, outpostLoss, squadDestroyed, outpostEmptied | 路边伏击 |
| outpostDecayed | cityId, loss, pop | 掉兵飘字 |
| stanceChanged | cityId, stance | 驻兵状态提示 |
| squadRetargeted | squadId, to, via, arrivalTick | 改道后刷新路线 |
| squadStarved | squadId, owner, loss, count, destroyed | 断粮掉兵提示 |

### 5.7 粮仓与临时驻兵点

完整决策见 [ADR 0002](adr/0002-granary-outpost.md)。本节只列执行合同。

**据点种类**

| kind | 产兵 | 产金币 | 可升级 | 计入胜负 | 备注 |
|---|---|---|---|---|---|
| town | 是 | 是 | 是 | 是 | 原城镇 |
| granary | 否 | 否 | 否 | 否 | 容量 50，防御 1.30 |
| outpost | 否 | 否 | 否 | 否 | 容量 50，防御 0.80，会掉兵 |

粮仓与驻兵点必须是叶子据点，只有一条支路连接公路节点。

**粮仓增幅**

- 己方拥有至少一座粮仓时，全体部队行军速度 +20%，攻防战斗力 +20%。
- 多座不叠加；空置粮仓也生效。
- 队伍出发时记录速度与战斗力增幅，途中粮仓易手不改变该队伍；防守方按战斗时的粮仓归属计算。

**临时驻兵点**

- 宽限 600 tick 后开始掉兵，每 200 tick 掉 2 兵；友军增援重置宽限期。
- 掉到 0 兵时变中立，状态回到避战。
- 状态：`evade` 避战、`engage` 迎战；默认避战，攻占后重置为避战。
- 迎战时，敌方队伍经过 `watch` 边会被拦截；拦截点在边中点。
- 拦截不占领据点：路过方胜则守军全灭、据点中立，路过方损失后继续；守方胜则路过方全灭。
- 敌方直接以驻兵点为目标时，无视状态强制交战；胜方占领。
- 驻兵点不计入城镇数与胜负。

**战斗**

```text
A = floor(队伍兵力 × 攻击方增幅 / 1000)
D = floor(守军人口 × 据点防御千分比 × 防守方增幅 / 1000000)

A > D: 守军全灭；进攻方损失 = min(兵力, floor(D × 1000 / 攻击方增幅))
否则:   进攻方全灭；守军剩余 = min(原人口, max(0, D - A))
```

无粮仓时增幅为 1000，退化为原版战斗。

### 5.8 兵团粮草

- 每个兵团出发时携带 `rules.supply.carryTicks` 的安全行军时间。
- 出发当 tick 不消耗；之后每 tick 消耗 1，归零后按 `starveIntervalTicks` 掉 `starveLoss` 兵。
- 改道、战斗损失、迎战拦截都不重置粮草；首版没有粮仓补给或队伍合并。
- 粮草归零发 `squadStarved`；兵力归零则队伍消失，不再参与到达结算。
- UI 在选中兵团的信息卡显示剩余秒数与断粮节奏；断粮时颜色变红。
- 默认 600 / 200 / 1，即 30 秒安全期，之后每 10 秒掉 1 兵。

### 6.4 哈希与回放

- 哈希输入：tick、seed、slug、status、winner、finishReason、nextSquad、rules、玩家金币、所有据点、所有队伍；按 id 排序。据点包含 kind、stance、decayAtTick、watch；队伍包含 pathIndex、legStartTick、legEndTick、speedMilli、strengthMilli、supplyLeft、nextStarveTick、intercepted。

## 7. 模拟核心实现

### 7.1 tick 顺序

1. 应用本 tick 指令：校验、扣人口、生成 squad、升级、切换驻守状态、改道。
2. 城镇人口增长与金币收入，按据点 id 升序。
3. 队伍推进：先结算迎战拦截，再推进中间节点与最终到达，按 squadId 升序。
4. 战斗结算，更新据点归属与人口。
5. 兵团粮草消耗与断粮掉兵。
6. 临时驻兵点掉兵。
7. 检查胜负与时间上限。
8. 汇总本 tick 事件；tick +1。

### 7.2 边界情况

- 据点人口为 0 但仍归属某玩家；下一次任何进攻都能占领。
- 队伍到达时目标已不存在，直接丢弃并记 rejected。
- 同一 tick 多队到达同一据点，按 squadId 升序；后到队伍按最新归属结算。
- 增援超过容量，溢出丢弃，不返还。
- 升级时人口刚好等于消耗，允许升级，人口变 0。
- 时间上限到达时，先结算本 tick 战斗，再判胜负。
- 队伍以驻兵点为目标时跳过路过拦截；迎战拦截只打一场遭遇战，不改变据点归属。
- 友军增援驻兵点会重置掉兵宽限期；掉到 0 兵立即变中立并回到避战。
- 同一 tick 多支队伍经过同一条监视边，按 squadId 升序依次与驻兵点结算。
- 改道在下一个节点生效；当前边不中途掉头，已经过的岔路口不能回选。
- `via` 不是下一节点邻居、或从 `via` 无法到达新目的地时拒绝。
- 同一 tick 同一队伍多次改道按指令顺序应用，最后一次生效。
- 改道不重置粮草；断粮掉兵归零时队伍立即移除，不再到达。
- 所有数组按 id 排序，禁止依赖对象键顺序。

### 7.3 确定性

- 禁止 Math.random、Date.now、performance.now 进入 sim。
- 随机只用种子 xorshift128+；首轮 AI 可以完全确定，不需要随机。
- 边长度在 map JSON 里写死为整数；sim 运行时不做 sqrt 路径计算。
- 战斗、人口、金币、路径代价用整数；速度换算用整数除法后向上取整，保持跨平台稳定。
- 等长路径按城市 id 字典序选择，保证稳定。
- 路径缓存按 from/to 排序键；不能依赖 Map 插入顺序。
- state hash 覆盖所有影响结果的字段。

## 8. 3D 与渲染

### 8.1 场景

- 首图是可拖动的桌面沙盘；Frontier 01 为 176 × 128 m、40 个据点的大地图，据点间道路中位数 20.8 m。
- 建筑：8 类（步兵营、盾兵营、骑兵营、弓兵营、精兵营、弓箭塔、粮仓、矿区）× 3 级（L1 营地 / L2 驻所 / L3 要塞）；屋顶、旗帜、盾徽用阵营色，轮廓和附属结构区分类别与等级。
- 据点：**一个据点一栋主建筑**，不再堆多栋房子；平台半径 3.45 m，石墙半径 3.3 m，建筑按据点 id 稳定选择类型，等级 L1–L3 对应建筑等级；村落用木墙，城镇与要塞用石墙。
- 行军：客户端在 60 dm/s 的基础上按 0.7 倍放慢，视觉移动更稳；sim 默认规则保持不变。
- 地形：低模三角网格，网格约 3 m；城镇与道路附近压平，空地形成 0–1.6 m 起伏草丘，地图边缘有向下裙边；草丘、灰色岩脊和干地台地三类模型。树、石、灌木按地形高度落位。
- 地形与道路：道路按直线走廊压平，弯曲路面从草丘之间穿过；据点平台始终落在压平的地块上。
- 道路：6 种模块（直道、C 型、上坡、下坡、十字、T 型），路宽 1.6 m；实际地图边用 CatmullRom 生成弯曲路面，不再全部两点一线；保留中央环岛与城镇路口广场。
- 通行：道路连续、直达的边可以正常通过；路线经过城镇节点时，只有己方据点可以借道，中立或敌方据点会阻断寻路，必须先攻城或改走连续支路。地图用 `transit: "friendly"` 开启，旧地图保持开放。
- 切换：`BuildingActor` 支持在任意建筑 / 等级 / 阵营之间做收缩—替换—回弹动画，模型统一原点、朝向 +Z、落地 y=0。
- 单位：步兵、盾兵、骑兵、弓兵、精兵 5 类 × 3 阵营，Q 版球体/胶囊造型（大头、短身、弱化手脚），哑光黏土 + 粗布质感；旧皮甲、划痕铁甲、木盾、补丁、锈迹、灰尘和金属铆钉用程序纹理。步兵戴眼罩/疤痕并持砍刀，盾兵铁盔大木盾，骑兵毛领长枪与小马，弓兵绿兜帽长弓，精兵轻铁甲、羽毛和破烂披风。`UnitActor` 带腿/臂/马腿行走循环，阵营色落在披风、兜帽、盾缘和马衣上。游戏内兵团按实际人数出模，单兵团只出一种兵种：城镇按 id 稳定对应一种兵营，驻兵点出弓兵，粮仓出步兵；队形 5 列，列距 0.44 m、行距 0.5 m，骑兵放宽到 0.78 m。骨架按兵种 + 阵营 + 变体缓存成模板，实例只 clone 节点，几何与材质共享。
- 预览：`?map=frontier01` 大地图，`?scene=buildings` 八类 × 三级（`&group=2` 第二组、`&team=0/1/2` 阵营），`?scene=towns` L1/L2/L3 组合，`?scene=roads` 六种道路，`?scene=switch` 切换动画，`?scene=units` 五类 × 三阵营单位。
- Frontier 01：32 座城镇、4 座粮仓、4 个临时驻兵点，2 个阵营。
- 地形、河流、树、石、道路都可有，但不要做第二生态。
- 先灰盒：方块地形、方块城、胶囊单位；灰盒可玩后再换美术。

### 8.2 相机

| 项 | 值 |
|---|---|
| 投影 | 正交 |
| 俯仰 | 55° |
| 方位 | 45° / 135° / 225° / 315° |
| 正交高度 | 34 m |
| 旋转中心 | 当前拖动焦点 |
| 过渡 | 620 ms |
| 缩放 | 0.7–2.4；按地图最大据点半径取初始值 |
| 平移 | 左键拖动地图，焦点限制在地图边界内 |
| 自由旋转 | 不允许 |
| 阴影 | blob 阴影 + 烘焙 AO |

- 相机位置由地图中心、方位、俯仰、距离计算；lookAt 地图中心。
- 初始缩放按最大据点半径自动适配；forest01 保持原视角，crossroads01 自动拉远。
- Q/E 旋转 90°；滚轮缩放；不做自由环绕。
- 点击命中优先用屏幕空间投影：把城市位置投到屏幕，命中半径 40 px；不做复杂 3D 拾取。

### 8.3 高低差测试场景

### 8.4 性能

- 首图上限：forest01 11 个据点、crossroads01 20 个据点；4 支队伍、20 个蒙皮单位、3 万三角面、80 draw call。

## 9. 页面与 UI

### 9.1 通用

- 分辨率：1280×720、1920×1080；16:9 优先。
- 语言：简中；所有文本走 key，不硬编码。
- 按钮：最小 44 px 高；hover、pressed、disabled 三态。
- 弹窗：暂停、退出确认、重开确认；ESC 行为一致。
- 加载：显示当前步骤；失败显示错误码与重试。
- 文本：最长文案不溢出；中文不用生僻字。

### 9.2 对局 HUD

- 左上：城镇数、总人口、金币；城镇数只统计 `kind === "town"`。
- 右上：计时、暂停按钮。
- 底部：选中城面板，显示等级、人口/上限、升级按钮、派兵提示；多选时在名称旁显示已选数量。
- 选中城：每座选中据点各有一个地面环。
- 可达高亮：按单位通行规则点亮所有可抵达的地面格（浅绿），可抵达建筑的占地为深绿。
- 多选：单击 Ctrl 切换单/多选模式；多选模式下点击己方据点编组，点击敌方据点、浅绿网格或深绿建筑占地指定目标，可连续编多组。
- 任务箭头：每组任务用浅绿色拱形箭头连接出发据点与目标；双击箭头取消该组任务。
- 派遣：多选时右下角“派遣”按钮确认发兵，所有编组同一 tick 出发；再次单击 Ctrl 退出多选并取消未派遣任务。
- 派兵：单选时点敌方据点立即发兵；也可以直接点浅绿网格或深绿建筑占地发兵，抵达网格后原地驻留。
- 战斗/占领：数字飘字、阵营色变化、音效。
- 胜利/失败：0.8 秒后进入结算页，不卡死。

### 9.3 页面验收

- 每个按钮都能点，且到达预期页面。
- 无重叠、无缺字、无截断、无无响应按钮。
- 暂停后继续，计时与模拟不跳变。
- 重开清空旧状态；返回主菜单再开始，状态干净。
- 设置修改后立即生效；返回主菜单不丢设置。
- 退出确认取消后回到原页面。

## 12. 禁止与取舍

**禁止**

- 禁止把原作 PNG、OGG、TXT、坐标、节点、UI 直接复制进项目。
- 禁止在 sim 里 import Three.js、DOM、Node API。
- 禁止在 sim 里使用 Math.random、Date.now。
- 禁止首轮加 Agent、服务器、法术、塔、城堡；粮草与临时驻兵点按 ADR 0002 执行，不在此列。
- 禁止自由 360° 镜头。
- 禁止为了“以后可能用”提前抽象复杂系统；先让一局跑通。

**取舍顺序**

进度落后时，按这个顺序砍：

1. 美术精度与音效。
2. 设置页的非必要项。
3. 动画与特效。
4. UI 装饰。

不要砍：

- 胜负与 15 分钟上限。
- 主菜单、暂停、结算、重开。
- forest01 的 7 城与 2 玩家。
- 粮仓增幅、驻兵点掉兵与迎战拦截的模拟规则。
- 3D 四向镜头。
- 确定性哈希。
