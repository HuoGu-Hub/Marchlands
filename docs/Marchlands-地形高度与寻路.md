# 地形高度与寻路

地形高度同时影响画面与图寻路，但**不改变地图拓扑**。行军仍然只能沿据点之间的道路移动。

## 高度场

`packages/map-authoring/src/height.ts` 提供纯函数 `createHeightField`：

- 输入：城市世界坐标、地形种子、起伏强度。
- 噪声：两层 value noise 加一层山脊噪声。
- 城市周围 4.2 到 7.4 米平滑压平，保证据点平台不悬空。
- 道路不再压平地形，道路网格沿高度场铺贴。

客户端 `terrain.ts` 与编辑器编译共用同一个高度场，避免“画面高度”和“寻路高度”不一致。

## 场景贴地

- 城市、装饰、兵团、地形块都使用 `heightAt` 定位。
- 道路中心线采样高度，路肩、路面、路缘分别抬升 0.035/0.05/0.07 米。
- 广场、环岛、路灯、选中环同样贴地。
- 编辑器点击使用射线与地形网格求交，坡地上的放置点不再落到 y=0。

## 坡度与寻路

编译地图时，对每条边采样 9 个点：

~~~text
rise = max(height) - min(height)
run  = lengthDm / 10
grade = clamp(rise / run, 0, 1)
~~~

`grade` 写入 `MapEdge.grade`。寻路代价：

~~~text
cost = round(length × (1 + grade × 3))
~~~

- Dijkstra 用 `cost` 选路，平地路线优先。
- 军团 ETA、分段 leg tick、迎战拦截时刻都使用 `cost`。
- 边的几何长度仍保留在 `length`，用于地图数据校验和渲染。
- 内置地图没有 `grade`，按平地处理。

## 数据示例

~~~json
{
  "from": "c1",
  "to": "c4",
  "length": 400,
  "grade": 0.042
}
~~~

## 限制

- 这是图寻路，不是网格 A* 或自由瓦片导航。
- 地形高度不参与碰撞、遮挡或视野。
- 军团视觉沿二维边插值后重新采样高度，不会沿坡面改变速度曲线。
