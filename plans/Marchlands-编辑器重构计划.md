# Marchlands 编辑器重构计划

**状态** 道路模型、自由端点道路、增量道路/装饰/地形/据点刷新、模式化工具区已实现  
**目标** 把编辑器从“能改数据”升级为“能顺手做地图”：自由道路、增量刷新、清晰工具层级  
**原则** 不自动替用户做连接；道路是显式对象；场景只重建脏层

---

## 1. 现状

底层已经具备网格导航、烘焙地形、自由寻路与网格兵团移动，但编辑器仍停留在据点图时代的交互模型。

已确认的问题：

- 新增据点时，数据层 `addSite` 不修改 `roads`；用户看到的路来自旧草稿、当前工具状态或既有道路穿过新据点。编辑器缺少回归测试来锁死“新增据点不产生道路”。
- 道路只有 `from/to`，没有独立 ID、控制点与固定宽度；`RoadDraft.path` 和 `widthDm` 字段虽然存在，但编辑器没有入口。
- 每次提交都走 `commit() → rebuild(true)`：
  - 重新 `compileDocument`，包含网格城镇可达性 A* 校验。
  - 重新 `createGame` 生成预览。
  - `dispose()` 整个 `BattleScene`，重新加载建筑、单位、地形与全部装饰。
  - 因此拖动一个装饰、刷一次地形都会触发全场景重建。
- 左侧工具、资产、地形、装饰、资产包全部纵向堆叠，装饰数量多时滚动很长。
- 道路只能通过“点两个据点”生成，形状不可编辑，宽度只能全局设置。

## 2. 目标

1. 新增据点绝不自动生成道路。
2. 道路可以手动画：点击或拖动生成控制点，拖动控制点改变形状，宽度固定。
3. 道路是独立对象，可以有端点据点，也可以没有端点。
4. 编辑操作只刷新受影响图层，不重建整个场景。
5. 左侧按模式分层，右侧只显示当前选择或当前工具的属性。
6. 旧据点图地图、旧草稿、试玩与回放不退化。

## 3. 非目标

- 不做战争迷雾。
- 不做多人同步。
- 不做官方三图自动迁移。
- 不做建筑内部编辑。
- 不在本轮重做美术资源。

## 4. 道路模型

### 4.1 文档

```text
RoadDraft
  id: string
  from?: CityId
  to?: CityId
  path: [number, number][]   // 分米，至少两个点
  widthDm: number            // 固定宽度，默认 16
  style?: RoadStyle          // 可选，缺省用地图全局风格
```

- 有 `from/to`：同时参与据点图边编译。
- 没有 `from/to`：自由道路，只进入视觉与网格速度层。
- 旧 schema 2 文档升级时，每条旧路生成 `id`、两个端点的直线 `path` 与默认宽度。

### 4.2 运行时

`MapDef` 增加 `roads?: MapRoadDef[]`：

```text
MapRoadDef
  points: [number, number][]  // 分米
  widthDm: number
  from?: CityId
  to?: CityId
```

- `edges` 继续供据点图模拟使用。
- `roads` 供客户端渲染，以及后续网格道路速度层使用。
- 旧地图没有 `roads` 时，客户端继续用 `edges` 画直线。

### 4.3 编译

- 有端点的道路：生成 `edges` 时使用 `path` 首尾与折线长度；同时写入 `roads`。
- 无端点的道路：只写入 `roads`。
- 端点必须存在，路径至少两个点，宽度在 6–60 分米。
- 道路不再自动寻找最近据点，不再自动补连接。

## 5. 道路编辑

### 5.1 工具

- 道路模式默认进入“画路”。
- 单击添加控制点，连续单击形成折线。
- 双击、Enter 或右键结束。
- 拖动控制点实时改形状，宽度不变。
- 右键控制点删除；双击线段插入控制点。
- 端点靠近据点时吸附并写入 `from/to`。
- Esc 取消当前道路。
- 一次画路只产生一次撤销记录。

### 5.2 渲染

- 控制点显示为可拖动圆点，线段高亮。
- 末端显示预览线与吸附点。
- 道路宽度从 `widthDm` 读取，缺省 16。
- 道路与地形贴合，使用现有地形高度采样。

### 5.3 选择与属性

- 选中道路后，右侧显示：端点、控制点数、总长度、宽度、风格、反转、删除。
- 宽度修改只影响当前道路。
- 端点清理按钮：把有端点道路变成自由道路，或把自由道路吸附到据点。

## 6. 性能

### 6.1 场景分层

把 `BattleScene` 拆成可独立刷新：

- `terrainLayer`
- `roadLayer`
- `siteLayer`
- `propLayer`
- `squadLayer`

编辑器只重建脏层：

- 移动据点：更新 `siteLayer`，道路端点跟随。
- 移动装饰：更新单个对象位置。
- 刷地形：只重建 `terrainLayer` 与贴地对象高度。
- 改道路：只重建 `roadLayer`。
- 改建筑外观：只重建对应 site view。

### 6.2 编译与校验

- 文档保存一个 `revision`，编译结果按 revision 缓存。
- 拖动过程中不编译；指针抬起后编译一次。
- 网格可达性 A* 只在以下时机执行：保存、试玩、手动校验。
- 预览不再每次 `createGame`；编辑态用静态城市预览，试玩才创建模拟。

### 6.3 资产缓存

- GLB 模板、材质、纹理按 assetId 缓存，跨重建复用。
- 地形网格按高度版本缓存，未改高度不重建。
- 装饰使用 InstancedMesh 或对象池，避免 68 个对象逐个创建。

### 6.4 目标

- 移动据点/装饰：单次更新 < 16 ms。
- 拖动道路控制点：稳定 60 fps。
- 保存与试玩前编译：60×60 网格 < 50 ms。
- 打开编辑器：< 1.5 s，且不重复加载同一 GLB。

## 7. UI

### 7.1 布局

- 顶部：返回、名称、撤销/重做、保存、试玩。
- 左侧：模式切换（据点 / 道路 / 地形 / 装饰 / 设置），只展开当前模式的工具。
- 右侧：当前选择检查器；没有选择时显示地图概览。
- 底部：状态、错误数、坐标、笔刷尺寸。

### 7.2 资产面板

- 分类折叠：建筑、城镇、树木、岩石、植物、地形块。
- 搜索框与最近使用。
- 不再一次性铺开全部 68 个装饰。
- 拖拽与点击放置都保留。

### 7.3 道路面板

- 宽度、风格、控制点列表。
- 平滑开关；平滑只影响渲染，不改变控制点。
- 删除、反转、吸附到据点。

## 8. 阶段

### 阶段 0：回归与基线

- 新增“放置据点不改变道路”测试。
- 记录当前编辑一次装饰/地形的耗时。
- 确认旧三图与旧草稿可打开。

### 阶段 1：道路数据与渲染

- RoadDraft/MapRoadDef 模型、迁移、编译、校验。
- 客户端按 `path` 渲染折线道路。
- 旧地图无 `roads` 时回退到 `edges` 直线。

### 阶段 2：场景分层

- 拆出 terrain/road/site/prop 图层。
- 编辑器增量刷新接口。
- 资产缓存与地形缓存。

### 阶段 3：道路交互

- 画路、加点、拖点、删点、结束、取消。
- 吸附与端点写回。
- 撤销合并、属性面板。

### 阶段 4：UI 重构

- 左侧模式化、资产分类与搜索。
- 右侧上下文检查器。
- 移动端与窄屏不崩。

### 阶段 5：验证与交付

- 单测：道路编译、迁移、撤销、端点。
- e2e：画一条弯路、拖控制点、保存重开、试玩。
- 性能基准与 EXE 重新打包。

## 9. 验收

1. 放置新据点后，`roads.length` 与 `edges.length` 都不变。
2. 画一条至少 3 个控制点的道路，拖动中间点后形状改变，宽度不变。
3. 保存、重开、试玩后道路形状与宽度一致。
4. 移动装饰不触发 GLB 重载与全场景重建。
5. 左侧同时可见的工具不超过 8 个；装饰分类可折叠。
6. 旧三图行为不变，旧 schema 2 文档可升级。
7. 网格图刷地形后，道路与建筑贴地正确。

## 10. 防跑偏

- 不自动连接道路。
- 不把道路形状存成只读缓存。
- 不为了性能牺牲撤销粒度。
- 不在本轮引入视野。
- 每次提交只做一个阶段。
- 旧据点图继续可玩。

## 11. 风险

- 道路从“边”变成“对象”会影响编译、校验与试玩，需要先做迁移与回退。
- 场景分层会触碰现有 `BattleScene` 的创建流程，需要保持只读游戏画面不变。
- 自由道路在据点图模式下不参与模拟，必须在 UI 上明确说明。
- 性能优化容易变成重写，先用测量锁定瓶颈，再逐层替换。
